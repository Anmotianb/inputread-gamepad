# Inputread 手柄朗读控制

用游戏手柄操作 [inputread](https://inputread.site/) 阅读页：暂停/继续朗读、上一段/下一段、重播、单词“看图片”、虚拟光标和页面滚动。

A Chrome/Edge extension (Manifest V3) that lets you read inputread.site with a gamepad: read-aloud control, paragraph navigation, word images, virtual cursor and scrolling. Unofficial, local-only, no data collection.

> **非官方项目**：与 inputread.site 的开发者没有隶属关系。扩展只调用网页上已有的按钮，不修改网站代码，不抓取、保存或上传书籍内容。

## 功能

| 按键 | 功能 |
| --- | --- |
| ↑ | 暂停 / 继续网页自带的朗读播放器；播放器没打开时不会启动新的朗读 |
| ↓ | 重播当前朗读段落 |
| ← | 上一段 |
| → | 下一段 |
| Y | 暂停 / 继续朗读 |
| RB | 打开单词解释框里的“看图片”；在图片页再按一次返回阅读页 |
| B | 关闭单词解释框 |
| X | 收藏解释框中的单词 |
| A | 在虚拟光标处左击；在段落空白处连按两次朗读该段 |
| 左摇杆 | 移动网页内虚拟光标 |
| 右摇杆 | 上下滚动页面（图片页同样可用） |

左摇杆控制的是阅读页内的虚拟光标，不会移动系统鼠标。光标在移动时出现，松开约 1 秒后隐藏。在段落文字左右空白处连续按两次 A（或用鼠标双击），会朗读该段；双击文字本身不会触发。

朗读单位跟随网页自己的分段：上一段/下一段和重播操作的是正文每个段落后的小喇叭（`data-aloud-from`）；如果网页提供逐句按钮，则优先用逐句按钮。暂停键只操作朗读播放器的“暂停朗读/继续朗读”按钮，不会去点正文按钮。

## 安装（Chrome / Edge）

1. 下载或克隆本仓库，保留整个文件夹。
2. 打开 Chrome 的 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角的“开发者模式”。
4. 选择“加载已解压的扩展程序”，选中本仓库文件夹。
5. 回到 inputread 阅读页，按一次手柄按键唤醒检测；点击工具栏图标可查看状态。

更新时：在扩展页点“重新加载”，再刷新 inputread 阅读页。只点“重新加载”不会替换已经打开的页面里的旧脚本。

弹窗底部会显示扩展版本和页面脚本版本；如果提示“页面仍在运行旧脚本”，按 F5 刷新。

> GitHub 只提供源码，Chrome 不能直接安装 ZIP；需要“加载已解压的扩展程序”。想要一键安装，需要上架 Chrome 应用商店（需要开发者账号、图标、截图、隐私政策和审核）。

## 权限与隐私

- `storage`：只用来记住“由手柄打开的图片标签页”，关闭标签页即清除；不读取浏览历史。
- 站点访问：`inputread.site`（阅读页），以及 Google/Bing 图片页（图片页的滚动和 RB 返回）。
- 不联网上传数据，不包含统计/广告代码，不收集书内容、账号或按键记录。

详见 [PRIVACY.md](PRIVACY.md)。

## 兼容性

- Chrome / Edge，Manifest V3。
- 标准 Gamepad 布局：方向键按钮 12–15，A/B/X/Y 按钮 0–3，RB 按钮 5，右摇杆纵轴 3。
- 手柄驱动（如 Steam Input）如果把手柄同时映射成键盘，扩展会在手柄按键按下时拦截对应按键的默认滚动，避免一次按键触发两次动作。

## 常见问题

- **弹窗显示“当前标签不是 inputread，或页面脚本尚未加载”**：先在扩展页重新加载，再刷新阅读页。
- **上一段/下一段没反应**：先把章节朗读播放器打开/开始朗读；正文小喇叭只在朗读模式可用时出现。
- **方向键偶尔乱跳**：1.11.1 已修复朗读单位混入、索引错位、自动滚动锚点漂移和驱动键盘重复滚动，细节见 [CHANGELOG.md](CHANGELOG.md)。
- **看图片跳的是 Bing**：本扩展打开词卡里链接当前的地址；如果安装了会改写成 Google 图片的扩展（如 Reading Ledger），就跳 Google，否则就是网站默认的 Bing。
- **没有手柄**：用键盘和鼠标时不需要本扩展；它不影响正常阅读。

## 项目结构

```
manifest.json      Manifest V3 配置
content.js         阅读页：手柄轮询、朗读导航、暂停、虚拟光标
images.js          图片页：右摇杆滚动、RB 返回
background.js      打开/关闭图片标签页并记住来源
popup.html/css/js  工具栏状态面板
```
